Configuració de les claus d'API per a Extracció IA

La digitalització integra Google Cloud Vision API (OCR) per extreure les lletres del tiquet i, posteriorment, Google Gemini API per realitzar el raonament, organitzar els camps (proveïdor, import, data) i automatitzar completament el formulari. Les claus es guarden localment al navegador (localStorage).

Com aconseguir les claus de l'API de Google?

  1. Ves a la consola de Google AI Studio per obtenir la teva clau gratis de Gemini Key.
  2. Per a la clau de Vision API, accedeix a la consola de Google Cloud, habilita "Cloud Vision API" i genera una credencial de Clau d'API estàndard de projecte.
  3. Si vols fer una prova immediatament, clica al botó "Carregar dades de prova" superior per veure i exportar dades reals sense connectar claus!
